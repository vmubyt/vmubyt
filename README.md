Community bot with moderation, games, and automation features.
- Auto-syncs latest website updates and news directly into Discord
- Interactive guessing mini-games with dynamic live leaderboards
- Automated chat moderation and anti-toxic filter
- Social media webhook integration (Twitter/X to Discord)
- Community points and giveaway reward system

- Supports multiple active channels and simultaneous players
- Persistent score tracking and server-wide rankings

### [SERVER48 Community Website](https://server48.my.id/)
Web platform that collects, processes, and redistributes public JKT48 information into a community-oriented format.
- Real-time data aggregation for schedules, news, and member profiles
- Integrated live streaming player (Showroom & IDN Live) with multi-room viewing and live chat
- Fast, clean, and mobile-friendly dark mode interface
- Built with focus on security, client-bundle hardening, and performance
